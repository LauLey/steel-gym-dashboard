# Panel de Administración Steel Gym
Panel administrativo diseñado para Steel Gym con el objetivo de centralizar y visualizar información relacionada con usuarios, ventas, inventario, membresías, personal, rentas, mantenimiento, reportes y operaciones diarias.

## Funciones

- Gestión de usuarios
- Control de ventas y pagos
- Gestión de inventario
- Gestión de membresías
- Control de rentas
- Gestión de personal y entrenadores
- Control de mantenimiento
- Reportes y estadísticas
- Resumen de operaciones diarias

## Tecnologías

- HTML
- CSS
